# Adigun Edition authoring

Adigun is creating an original English Bible edition under the owner's direction. It is its own version, with its own text and identity. It is not sourced from a third-party Gen Z product.

## Source basis

The edition is authored from the project's pinned World English Bible text (`eng-web`). The WEB publisher dedicates the text to the public domain and expressly permits adaptation and redistribution, asking that changed text not use the WEB name: [official WEB notice](https://ebible.org/engwebp/copyright.htm). The new edition identity is **Adigun Edition** (`adigun-genz` is the existing internal data identifier).

The edition preserves the project's WEB 66-book order and every source chapter/verse address. It uses original, clear contemporary English in the owner's chosen voice, without forcing slang or changing the source meaning. Genesis 1:1–3 begins with wording supplied by the project owner.

## Authoring state

- Complete chapter candidates now cover Genesis 1–18, all 458 verses, under `content/genz/ot/GEN/`; each chapter has its own numbered JSON file.
- Authoring scope is the complete 66-book WEB manifest.
- Work is divided by testament: primary Codex owns the Old Testament; the assigned second agent owns the New Testament. Their file paths are disjoint.
- Candidate text remains separate from the installed edition until full corpus and chapter coverage are validated. The reader must not present the existing WEB-plus-editorial overlay as the Adigun edition.

No third-party Gen Z text is used. Do not reintroduce labels, notices, or catalog claims that describe Adigun Gen Z as anything other than its own Bible edition.

# Adigun Edition authoring

Adigun is creating an original English Bible edition under the owner's direction. It is its own version, with its own text and identity. It is not sourced from a third-party Gen Z product.

## Source basis

The edition is authored from the project's pinned World English Bible text (`eng-web`). The WEB publisher dedicates the text to the public domain and expressly permits adaptation and redistribution, asking that changed text not use the WEB name: [official WEB notice](https://ebible.org/engwebp/copyright.htm). The edition identity is **Adigun Edition** (`adigun-edition`).

The edition preserves the project's WEB 66-book order and every source chapter/verse address. It uses original, clear contemporary English in the project's chosen voice, without adding slang or changing the source meaning. Genesis 1:1–3 begins with wording supplied by the project owner.

## Authoring state

- Complete chapter candidates now cover Genesis 1–21, all 548 verses, under `content/genz/ot/GEN/`; each chapter has its own numbered JSON file.
- Authoring scope is the complete 66-book WEB manifest.
- Work is divided by testament: primary Codex owns the Old Testament; the assigned second agent owns the New Testament. Their file paths are disjoint.
- Reader integration publishes only completed chapters in an explicitly scoped portion manifest. The reader never substitutes WEB wording for missing Adigun text or presents an editorial overlay as the Adigun Edition.

No third-party edition text is used. The reader name is **Adigun Edition**.

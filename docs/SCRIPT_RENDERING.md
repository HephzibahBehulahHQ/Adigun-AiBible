# Arabic and Myanmar source rendering

Work in progress on `codex/multiscript-reading-20261105`, separate from the current release candidate. This branch prepares source-script rendering for the Arabic Van Dyck and Burmese Judson editions. It does not change any Scripture bytes or grant editorial approval.

Two original variable fonts are pinned to `google/fonts@fbe81817505e8aeadc53cc7a38a2b76fb57c333e`: Noto Naskh Arabic and Noto Sans Myanmar. Their original bytes and complete SIL Open Font License 1.1 notices are preserved. Local filenames omit axis punctuation; internal font data is unchanged. `public/fonts/sources.json` records original URLs, upstream Git blob identities, exact byte counts and SHA-256 digests. Combined font payload: 1,092,424 bytes.

Implemented in this work branch: source direction and typography in reader/comparison, font-ready share/widget/multiple-card layouts, explicit canvas RTL alignment with LTR credits restored, grapheme-preserving wrap slices, and source-font styles in print/projection. Original Scripture bytes remain unchanged.

Independent FontTools inspection of all actual Arabic Van Dyck and Burmese Judson book text found 47 Arabic-script and 64 Myanmar-script codepoints; every one is present in the respective pinned font cmap. Seventeen focused typography/passage-card/widget tests pass, including exact wrap reconstruction, mixed-script drawing, RTL widget anchors, source font readiness failure and existing Yoruba/English behavior. Combined TypeScript and lint passed. The production build verifies 1,742 packaged source payloads; the final browser gate remains pending.

The three public/fonts notices/provenance files now belong to the verified offline shell. A packaging regression verifies their hashes and rejects missing notices. The Myanmar wrapper uses exact ICU word units; all 1,672,136 units in the actual source retained dependent vowels. Oversize indivisible units trigger smaller single-card/widget fonts or an explicit fit failure. PNG and WebM capture immutable source canvases, check the prepared revision after permission resolution, and cancel recordings when the preview changes. Actual desktop/mobile/320px/offline rendering and screenshot review remain required, The twelve-source batch and the prior release safeguards are integrated; TypeScript/lint/build passed; exact-candidate browser CI remains pending. This checkpoint is not a released feature.
